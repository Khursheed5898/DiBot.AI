3. Deployment & DevOps Challenges Solved
# Challenge Root Cause Engineering Solution
1 Out-Of-Memory (OOM) 1 GB RAM instance ran out of memory during npm build. Configured 2 GB Linux Swap Space (/swapfile).
2 Node.js Version Conflict Amazon Linux default Node v18 incompatible with Vite 7. Upgraded OS to Node.js 20 LTS (v20.20.2).
3 Infinite Postinstall Loop Circular npm install --prefix server script call. Installed using npm install --ignore-scripts flag.
4 Nginx Default Proxy Issue Default Nginx config overrode custom reverse proxy. Created /etc/nginx/default.d/dibot.conf using sudo tee.
5 MongoDB Atlas IP Block Cloud DB rejected connections from EC2 IP. Whitelisted 0.0.0.0/0 in Atlas Network Access.
4. Top Technical Interview Questions & Answers
Q1: Why WebSockets (Socket.io) instead of HTTP REST for AI Debates?
HTTP REST requires polling overhead. WebSockets provide full-duplex, bi-directional token streaming, allowing LLM responses to stream word-by-word into the UI with minimal latency.
Q2: What is the role of Nginx in front of Node.js?
Nginx acts as a Reverse Proxy listening on Port 80 and forwarding requests to Express on Port 5000. It handles WebSocket protocol upgrades (Upgrade/Connection headers) and abstracts internal ports.
Q3: Why use PM2 instead of running `node server.js` directly?
PM2 is an enterprise process manager providing zero-downtime auto-restarts on uncaught exceptions, system boot survival (`pm2 startup`), and real-time CPU/RAM telemetry (`pm2 monit`).
Q4: How did you optimize the app for a 1GB RAM AWS EC2 instance?
1) Offloaded heavy LLM compute to cloud APIs (Gemini/Groq). 2) Configured 2GB Swap Memory. 3) Built optimized React static production bundles served via Express.
Q5: How is Authentication handled in DiBot.Ai?
Stateless JWT authentication. Passwords are hashed with `bcryptjs`. Upon login, a signed JWT is stored in `localStorage` and sent in HTTP Authorization headers verified by Express middleware.
Q6: What is the difference between `npm install` and `npm ci`?
`npm install` resolves version ranges and mutates lockfiles. `npm ci` strictly installs exact versions from `package-lock.json`, making it 10x faster and deterministic for deployment.
Q7: How would you scale DiBot.Ai for 100,000 active debaters?
1) AWS Application Load Balancer (ALB) across EC2 instances. 2) Socket.io Redis Adapter for cross-server WebSocket state. 3) MongoDB Atlas database sharding and index optimization.
