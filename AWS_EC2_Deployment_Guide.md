## 🚀 Part 1: Initial Deployment (Step-by-Step)

### Step 1: System Update & Install Node.js 20 LTS

Upgrades Node.js from default v18 to v20 LTS to satisfy dependencies for React Router 7 and Vite 7.

```bash
sudo dnf remove -y nodejs
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo dnf install -y nodejs git nginx
node -v
```

---

### Step 2: Configure 2GB Swap Memory

Prevents Out-Of-Memory (OOM) crashes during build operations on 1GB RAM instances.

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

### Step 4: Install Dependencies & Build React Frontend

```bash
# Install root packages (bypassing recursive postinstall)
npm install --ignore-scripts

# Install server packages
cd server && npm install --ignore-scripts && cd ..

# Build React frontend bundle (dist/ folder)
npm run build
```

---

### Step 5: Configure PM2 Process Manager (24/7 Execution)

```bash
sudo npm install -g pm2
pm2 start server/server.js --name "dibot"
pm2 startup
```

> **Important**: Copy and execute the `sudo env PATH=...` command generated by `pm2 startup`, then run:

```bash
pm2 save
```

---

### Step 6: Configure Nginx Reverse Proxy (Port 80 -> 5000)

```bash
sudo tee /etc/nginx/default.d/dibot.conf > /dev/null << 'EOF'
location / {
    proxy_pass http://localhost:5000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection 'upgrade';
    proxy_set_header Host $host;
    proxy_cache_bypass $http_upgrade;
}
EOF

sudo systemctl enable nginx
sudo systemctl restart nginx
```

---

### Step 7: MongoDB Atlas Network Access (IP Whitelist)

1. Go to [cloud.mongodb.com](https://cloud.mongodb.com) -> **Security** -> **Network Access**.
2. Click **+ Add IP Address**.
3. Add `0.0.0.0/0` (Allow Access from Anywhere).
4. Click **Confirm** and wait ~30s until status becomes **Active**.
5. Restart PM2 on EC2:
   ```bash
   pm2 restart dibot
   ```

### 2. Monitoring & Server Diagnostics

```bash
# View live application logs
pm2 logs dibot

# View last 50 lines of logs
pm2 logs dibot --lines 50

# Check process status and RAM usage
pm2 status

# Check server memory & swap utilization
free -h

# Check Nginx status
sudo systemctl status nginx
```

---

### 3. Emergency Troubleshooting Commands

```bash
# Restart Backend App
pm2 restart dibot

# Restart Nginx Web Server
sudo systemctl restart nginx

# If app hangs or memory spikes
sudo killall node npm
pm2 restart dibot
```
