📌 PART 1: Initial Deployment Steps (Tested & Verified)

Step 1: Install Node.js 20 LTS & Core Tools

Upgrades Node.js to v20 LTS to satisfy dependencies for React Router 7 and Vite 7.

sudo dnf remove -y nodejs
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo dnf install -y nodejs git nginx
node -v

Step 2: Configure 2GB Swap Memory

Prevents memory crashes during npm install & Vite build processes on 1GB RAM instances.

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

Step 4: Install Dependencies & Build Frontend

Uses --ignore-scripts flag to bypass postinstall recursion and complete build cleanly.

cd server && npm install --ignore-scripts && cd ..
npm run build

Step 5: Configure PM2 Process Manager (24/7 Execution)

sudo npm install -g pm2
pm2 start server/server.js --name "dibot"
pm2 startup
pm2 save

Step 6: Configure Nginx Reverse Proxy (Port 80 → Port 5000)

sudo tee /etc/nginx/default.d/dibot.conf > /dev/null << 'EOF'
location / {
    proxy_pass http://localhost:5000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection 'upgrade';
    proxy_set_header Host $host;
    proxy_cache_bypass $http_upgrade;
}
EOF

sudo systemctl enable nginx
sudo systemctl restart nginx

Step 7: Whitelist EC2 IP in MongoDB Atlas

Go to cloud.mongodb.com → Security → Network Access → Add 0.0.0.0/0 → Click Confirm.

pm2 restart dibot
