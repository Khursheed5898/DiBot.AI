# Project Requirements: DiBot.Ai

## Functional Requirements
- [x] **Debate Logic**: AI must participate in structured debate rounds.
- [x] **Real-time Analytics**: Calculate pacing, filler words, and argument strength.
- [x] **Transparent Reasoning**: Display AI "thoughts" alongside responses.
- [ ] **Adaptive Difficulty**: Dynamically adjust AI tone and logic tightness (WIP).
- [ ] **Fallacy Detection**: Identify logical fallacies in real-time.

## Non-Functional Requirements
- **Performance**: Real-time feedback with low latency.
- **Aesthetics**: Premium "Mercury" metallic and glassmorphism design.
- **Scalability**: Support multiple concurrent debate sessions.
- **Accessibility**: Eye-friendly themes and clear typography.

## Technical Constraints
- Frontend: React 19 / Vite.
- AI: Google Gemini API.
- Database: MongoDB.
